# Risk Copilot Predictive Model Card

## Status

**Not yet validated for production use.**

The training and evaluation pipeline is implemented, but this repository must not claim final model performance until the public-repository research cohort passes the data-quality gate and produces a held-out evaluation report.

## Intended use

The model is intended to estimate delivery-risk severity from point-in-time engineering signals before a project delivery target is due.

It is decision support, not an autonomous delivery decision-maker.

## Inputs

The model uses structured engineering-delivery signals such as issue backlog, pull-request activity, issue age, scope movement, review latency, commit activity, contributor activity, and prediction horizon.

It does not use the legacy human-authored risk label as a predictor.

## Output

Class probabilities for:

- On Track
- Delayed
- Critical

Risk score:

`100 × (0.5 × P(Delayed) + P(Critical))`

This score represents expected severity rather than prediction confidence.

## Evaluation

Required reporting includes grouped repository holdout, macro F1, precision, recall, confusion matrix, calibration/Brier score, and baseline comparison.

No values are written into this model card until generated by the evaluation pipeline.

## Known limitations

Public GitHub milestone data does not reliably expose historical due-date edits. The pipeline records this provenance explicitly and prevents unsupported claims about historical accuracy.

Public open-source repositories may not represent private enterprise delivery environments.

## Human oversight

High-risk conclusions are intended for human review. Scenario analysis is non-causal and should not be interpreted as guaranteed intervention impact.
